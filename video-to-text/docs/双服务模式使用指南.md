# NoteForge 双服务模式使用指南

## 📌 两种服务模式

NoteForge 现在提供**两种独立的转写服务**,分别针对不同的使用场景:

| 服务 | 适用场景 | 输入方式 | 启动脚本 |
|------|----------|----------|----------|
| **B站在线视频转写** | B站在线视频URL | B站视频链接 | `bilibili-to-notes.bat` |
| **本地视频转写** | 本地已下载的视频文件 | 本地文件/目录路径 | `noteforge.bat` |

---

## 🎬 服务一: B站在线视频转写

### 使用场景
- 直接输入B站视频链接,自动完成下载音频+转写笔记全流程
- 无需手动下载视频,无需手动提取音频
- 适用于在线流媒体视频的快速转写

### 前置依赖
首次运行需要 `yt-dlp` 工具,脚本会**自动检测并安装**。

### 使用步骤

1. **启动服务**
   ```
   双击: video-to-text\bilibili-to-notes.bat
   ```

2. **粘贴B站视频链接**
   ```
   示例: https://www.bilibili.com/video/BV1YR5E6EE9o/
   ```

3. **输入笔记名称**
   ```
   示例: 课程01 / Python入门 / 剪辑技巧
   ```

4. **自动处理**
   - ✅ Step 1/3: 自动下载音频(使用yt-dlp)
   - ✅ Step 2/3: 转换音频格式(m4s→wav)
   - ✅ Step 3/3: Paraformer模型转写
   - ✅ 生成笔记到 `output/notes/` 目录
   - ✅ 自动清理临时文件

### 工作流程
```
B站视频URL → yt-dlp提取音频 → ffmpeg转wav → Paraformer转写 → 笔记生成
```

### 支持的B站链接格式
- `https://www.bilibili.com/video/BV1YR5E6EE9o/`
- `https://www.bilibili.com/video/av12345678/`
- `https://b23.tv/xxxxxx` (短链接)

---

## 📁 服务二: 本地视频转写

### 使用场景
- 已经下载到本地的视频文件
- 批量处理本地视频库
- 使用配置文件进行批量转写

### 前置依赖
需要安装 `ffmpeg` 工具(用于从视频中提取音频)。

### 使用步骤

1. **启动服务**
   ```
   双击: video-to-text\noteforge.bat
   ```

2. **选择转写模式**

   **模式1: 转写单个视频文件**
   - 输入完整视频文件路径
   - 示例: `D:\videos\course01.mp4`

   **模式2: 批量转写整个目录**
   - 输入包含多个视频的目录路径
   - 示例: `D:\videos\`
   - 会自动处理目录下所有视频文件

   **模式3: 使用配置文件批量转写**
   - 使用 `config/video-mapping.json` 中定义的映射配置
   - 适合有固定视频库的批量处理

3. **自动处理**
   - ✅ Step 1/3: 从视频中提取音频(ffmpeg)
   - ✅ Step 2/3: Paraformer模型转写
   - ✅ Step 3/3: 生成转写文本到 `output/transcripts/` 目录

### 工作流程
```
本地视频文件 → ffmpeg提取音频 → Paraformer转写 → 转写文本生成
```

### 支持的视频格式
- MP4, MKV, AVI, MOV, FLV, WMV 等主流格式

## 🔧 常见问题

### Q1: yt-dlp 是什么?
`yt-dlp` 是一个开源的命令行视频下载工具,支持从B站等多个视频平台提取视频和音频。

**手动安装命令:**
```bash
pip install yt-dlp
```

### Q2: ffmpeg 是什么?
`ffmpeg` 是一个强大的音视频处理工具,用于提取视频中的音频、转换音频格式等。

**安装方法:**
- 下载: https://ffmpeg.org/download.html
- Windows推荐使用 `winget install ffmpeg` 或从官网下载

### Q3: 转写结果保存在哪里?
- **B站视频**: `video-to-text/output/notes/` 目录
- **本地视频**: `video-to-text/output/transcripts/` 目录

### Q4: 转写支持的音频格式?
Paraformer 模型要求输入为 **16kHz, 单声道, 16bit** 的 WAV 格式音频。
脚本会自动完成格式转换,你无需手动处理。

### Q5: B站视频下载失败怎么办?
可能原因:
1. 视频链接无效或已失效
2. 视频需要登录权限(如大会员视频)
3. 网络连接问题或被B站限流
4. yt-dlp 版本过旧,建议更新: `pip install --upgrade yt-dlp`

### Q6: 两种服务能否混合使用?
可以! 两种服务相互独立,互不影响:
- 使用 `bilibili-to-notes.bat` 处理B站在线视频
- 使用 `noteforge.bat` 处理本地视频文件

## 📊 服务对比

| 特性 | B站在线视频 | 本地视频 |
|------|------------|----------|
| 输入方式 | B站视频URL | 本地文件路径 |
| 下载工具 | yt-dlp(自动) | 无需 |
| 音频提取 | 自动提取 | ffmpeg提取 |
| 网络依赖 | 需要 | 不需要 |
| 适用场景 | 在线流媒体 | 本地视频库 |
| 输出目录 | `output/notes/` | `output/transcripts/` |

## 🚀 快速开始

### 场景1: 看到B站好视频,想转成笔记
```
1. 复制B站视频链接
2. 双击 bilibili-to-notes.bat
3. 粘贴链接,输入名称
4. 等待生成笔记 ✅
```

```
1. 双击 noteforge.bat
2. 选择模式1(单文件)或模式2(批量)
3. 输入文件/目录路径
4. 等待生成转写文本 ✅
```
